# 概念 A「停車場 LED 看板」設計規格

## 1. 設計理念（3 點，各附真實物件對照）

1. **整個 App 是一塊停車場入口的點陣 LED 看板。** 真實物件：校門口「剩餘車位」電子看板。每頁頂端一塊鋁框黑底大看板，放該頁最重要的數字；看板下方是掛在牆上的簡潔列表（牆面米白）。
2. **像素只用在「燈會亮的地方」。** 對照：LED 看板上只有數字、標題字、圖示會發光；說明文字從來不是點陣。因此點陣/像素字型只用於數字、看板標題、標籤與圖示，中文內文用一般字型 15–17px，保持好讀。
3. **顏色是燈色，且有意義。** 對照：停車場看板用燈色分級。琥珀＝一般數值、綠＝充足/完成、紅＝緊急/滿位、青＝資訊（天氣、汽車、行事曆）。每種狀態另外有形狀與文字，不只靠顏色。

## 2. 骨架（每頁相同，但內容分格不同）

```
[狀態列]
[看板：鋁框 + 4 顆螺絲 + 黑底]
   標題列（看板標題 + 右側小字）
   分格（2px 格線）：該頁最重要的數字，點陣顯示
   公告列：捲動跑馬燈
[銘牌標題 + 點線] 例：今日課程
[列表：牆面上的列，底線 2px]
[分頁列：鋁條，當前分頁＝黑色燈格 + 琥珀圖示 + 粗體標籤]
```

- 首頁：下一堂倒數（大）｜氣溫｜機車車位 109。
- 停車：機車合計 109（大）｜汽車 12；列表每列右側是「迷你看板」顯示該場剩餘數。
- 課業：待交 3 件｜最近截止倒數 14:17（紅）；作業列用「燈色分級」，週課表是「看板分格」。
- 課業頁特色解法：作業按截止遠近用 紅／琥珀／綠／青 並搭配文字「今天／2天後／6天後／完成」；週課表把「今天」整列點亮成黑底琥珀字，其他天是白底細框，空堂是未點亮的空格。

## 3. 刻意避開清單

- 系統灰底＋白色圓角卡片、模糊陰影、藍色強調、SF 範本感（全部直角，格線 2px）。
- 只換配色（骨架、元件、字型都換）。
- 三頁同骨架但無特色：三頁共用看板骨架，分格與數字各不相同。
- 緩動動畫、emoji、「AI」字樣、英文口號、假功能（只有真實存在的「重新整理」）。
- 抄既有遊戲／品牌：不使用任何掌機四綠色，不用既有品牌名稱與介面。
- 純深色單調：下半部是牆面米白，看板只佔上方，避免整頁黑。

## 4. 字型與授權

- 像素字：俐方體 11 號 Cubic 11（SIL OFL 1.1，可商用），CDN：`https://cdn.jsdelivr.net/gh/ACh-K/Cubic-11@v1.500/fonts/web/Cubic_11.woff2`。只用於標題、標籤、數字，字級 12 / 24px。上架時建議把 woff2/ttf 放進 App bundle（Info.plist 註冊 UIAppFonts），並附 OFL 授權檔。
- 內文：`-apple-system, "PingFang TC", "Noto Sans TC", sans-serif`，15px（次要）/17px（列表主標，粗體）。
- 自繪點陣數字：5x7 字模，程式以 SVG path 畫出（不靠字型）；大數字 1 點＝10px（亮點 8px＋縫 2px）或 8px，列表迷你看板 6px，皆 2px 整數倍。熄滅燈珠以 `--dot-off` 畫出（LED 未點亮燈珠），亮點左上有 2×2 高光（燈珠反光）。

## 5. 色盤（9 色）與實算對比（WCAG 2.x，相對亮度公式）

| 變數 | Hex | 用途 | 實算對比 |
|---|---|---|---|
| `--board` | #0B0E12 | 看板黑底、銘牌、框線、牆面上的文字 | 見下 |
| `--dot-off` | #242B33 | 未點亮燈珠、看板分格線（純裝飾） | 對 board 1.35（裝飾，不承載文字） |
| `--amber` | #FFB400 | 一般數值、標題、下一堂、緊張 | 在 board 上 **10.85** |
| `--green` | #3FE08F | 充足、完成、本週課表 | 在 board 上 **11.30** |
| `--red` | #FF5A4D | 今天截止、滿位 | 在 board 上 **6.28** |
| `--cyan` | #5BD6FF | 氣溫、汽車、行事曆、完成標籤 | 在 board 上 **11.52** |
| `--alu` | #B9C0C8 | 鋁框、分頁列底、列表底線 | board 文字在其上 **10.53**；次要字 ink-sub 在其上 4.67 |
| `--wall` | #ECE9E0 | 牆面底色、看板上的內文字 | 在 board 上 **15.93**；board 在其上 **15.93** |
| `--ink-sub` | #454D56 | 牆面上的次要文字、完成作業 | 在 wall 上 **7.06** |

其他實算：board 在 amber 上（今天那一列的「三」）10.85。內文組合（wall/board、board/wall、ink-sub/wall）皆 ≥ 4.5:1；大字/圖示（LED 色在 board）皆 ≥ 3:1（最低 6.28）。alu 對 wall 1.51 僅用於 2px 分隔線，不承載資訊。琥珀在 wall 上僅 1.47，因此琥珀**絕不直接放在牆面**，一律放在黑底晶片或看板內。

狀態不只靠顏色：充足＝實心方塊＋「充足」、緊張＝三角形＋「緊張」、滿位＝叉叉＋「滿位」；作業用文字「今天／2天後／6天後／完成」。另外有 10 格燈條，亮幾格代表剩餘比例（含數字）。判定：剩餘比例 ≥30% 充足，<30% 緊張，0 滿位。

## 6. 紋樣／元件「只用在哪裡」

| 元件 | 只用在 | LED 看板上的對應 |
|---|---|---|
| 鋁框＋螺絲 | 每頁頂端看板 | 看板外框與固定螺絲 |
| 2px 格線分格 | 看板內部 | 看板分格 |
| 點陣大數字（含未亮燈珠） | 看板主數字、迷你看板 | 發光燈珠 |
| 跑馬燈公告列 | 看板最下一格 | 看板公告列 |
| 銘牌＋點線 | 列表區標題 | 看板下方的標示牌 |
| 迷你看板（黑底小格） | 停車列右側數字、時間、日期、作業狀態 | 分場次的小顯示器 |
| 10 格燈條 | 停車列剩餘比例 | 條狀燈 |
| 形狀標籤（方／三角／叉／箭頭） | 狀態 | 狀態指示燈 |
| 實色位移陰影（4px） | 只給可按的「重新整理」按鈕，按下位移蓋住 | 實體按鍵 |
| 反白＋黑底燈格 | 當前分頁、今天那天 | 亮起的指示 |

全頁沒有任何模糊陰影，`box-shadow` blur 全為 0。

## 7. 動態規則

- 招牌動態 1：公告列跑馬燈，`steps(180)`、12 秒線性循環，每步 4px。
- 招牌動態 2：課業頁倒數的冒號閃爍，`steps(1)`、2 秒。
- 無緩動、無其他動畫。`@media (prefers-reduced-motion: reduce)` 會停掉兩者，跑馬燈只顯示第一則公告。

## 8. SwiftUI 實作要點

- 元件拆分：`LEDBoardFrame`（鋁框＋螺絲，ViewModifier）、`LEDDisplay`（黑底＋格線 Grid）、`DotMatrixText`（點陣數字）、`LEDMarquee`、`NamePlate`、`MiniBoard`、`StatusTag`、`LEDBar`、`PixelTabBar`、`PixelButtonStyle`（按下位移）。
- 點陣怎麼畫：每個字元一個 5x7 的 `[UInt8]` 字模；`Canvas` 逐格 `fill(Path(CGRect))`，亮點用 LED 色，熄滅用 `dotOff`，再補 2×2 高光；`GraphicsContext` 關閉抗鋸齒（`context.fill` 搭配整數座標），格寬固定為 2pt 整數倍。倒數與數字可整段快取成 `Image`（`ImageRenderer`），配 `.interpolation(.none)`。
- 用 Canvas：點陣數字、跑馬燈（`TimelineView(.animation(minimumInterval: 1/12))` 每次位移 4pt）、像素圖示（8x8 字模）。一般 SwiftUI：列表、標籤、分頁列版面。
- 字型：Cubic 11 加入 bundle，`.font(.custom("Cubic 11", fixedSize: 24))`；內文用系統字型 15/17pt。
- 無障礙：點陣數字加 `.accessibilityLabel("剩餘 109 個機車車位")`，跑馬燈 `accessibilityHidden`；偵測 `accessibilityReduceMotion` 停動畫。

## 9. 文案語氣

簡短、公告式、像看板上的告示：「滿位」「剩 64」「2 天後」。不使用口號與感嘆號，標題一律中文。

## 10. 自評缺點

1. 跑馬燈與冒號閃爍外，整體偏靜態；點陣數字在 2pt 格下大量未亮燈珠，視覺較雜，閱讀速度略慢於平滑字體。
2. 課業頁週課表仍偏資訊密集，次要文字（節次，Cubic 12px）偏小，需要在實機上再放大測試。
3. 倒數 14:17 為由「今天 23:59 截止」與現在 09:42 推算（相差 14 小時 17 分），非原始資料；實作時由系統時間動態算。另外狀態列時間用 Cubic 24px 而非點陣，與看板點陣語言不完全一致。
